# CATÁLOGO MAESTRO DE DOCUMENTOS SG-SST (RESOLUCIÓN 0312 DE 2019)

Este catálogo define la estructura, ubicación y requerimientos para la generación de cada uno de los estándares exigidos por la normatividad colombiana en el SG-SST.

## Convenciones
- **ID:** Código único para referencia interna.
- **Fase PHVA:** Ciclo al que pertenece.
- **Ruta Carpeta:** Ubicación predeterminada dentro de la estructura `01_PLANEAR`, `02_HACER`, etc.
- **Inputs:** Datos específicos (adicionales a los básicos de la empresa) necesarios para generar el documento.
